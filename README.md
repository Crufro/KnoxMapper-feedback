# KnoxMapper Feedback

This is the place for bug reports, feedback, and feature ideas for **KnoxMapper**, a browser-based map authoring tool for Project Zomboid.

This repo is connected to the KnoxMapper Discord through **KnoxMapper Helper**. The bot turns posts in the `bug-reports` and `feedback-and-ideas` forums into GitHub issues so they can be tracked alongside development. Application and bot code are maintained in the main KnoxMapper repository; this repository holds the public feedback tracker.

[Browse tracked issues](https://github.com/Crufro/KnoxMapper-feedback/issues)

**The Discord server is not live yet. Public access is not available.**

## Public visibility

**Posts and human replies in the connected forums are copied to this public repository.** This includes report text, Discord display names on replies, and attachment links. Share only information you are comfortable making public, and remove passwords, personal information, and private data from screenshots or logs before posting.
